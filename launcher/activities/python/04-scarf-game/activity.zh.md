## The story
一个古老的童军游戏：两名玩家面对面，每人背后的腰带上塞着一条围巾。他们绕着对方转圈，想抢走对方的围巾。先抢到的人获胜。我们用 Thymio 来玩：“围巾”就是那一对后方传感器。

## Your goal
用按钮或遥控器驾驶你的 Thymio。如果它的某个后方传感器检测到东西，你的机器人就输了。

## Step by step
1. 前进、后退、左、右按钮（或遥控器按键）让机器人移动；中间按钮让它停下。
2. 当某个后方传感器（`prox_horizontal[5]` 或 `[6]`）检测到东西时，机器人必须：把速度设为 0，停止两个电机，并播放 3 秒钟的高音。
3. 开始时给每台机器人一个随机颜色，让玩家能区分它们。
4. 所有机器人使用同样的后方传感器阈值：这样才公平！

## Hints
1. 每个按钮用一个事件：`@onevent def button_forward():` 等等。
2. 使用遥控器时，用 `@onevent def rc5():` 并检测 `rc5_command`：80 上，81 下，85 左，86 右，87 中（遥控器 1）。
3. 输了：`nf_sound_freq(1000, 180)` 播放 3 秒钟的高音（180 = 3 × 60）。
4. 随机数：`math_rand()` 给出 -32768 到 32767 之间的值；`math_rand() // 5462 + 6` 给出 0 到 11，每种颜色一个数字。

## To go further
每按一次按钮就增加一点速度（变量 `gap`），控制得更精细。加上墙来玩：后背碰到墙也算输！

## For the teacher
一个遥控器能控制房间里所有的机器人，所以每台机器人必须听不同的按键（机器人 1：87/85/86/81/80，机器人 2：2/1/3/5/6，机器人 3：8/7/9/0/16）。有多台机器人时，由一名裁判宣布开始，并检查没有人用手。
