# Activity library

One folder per activity: `activities/<language>/<NN-name>/`

- `activity.md` – all the texts (title, level, age, story, goal, steps, hints, to go further). Plain text, edit it in any editor.
- `solution.<ext>` – the solution (`.vpl3`, `.sb3`, `.aesl` for Blockly and Aseba, `.py`).
  When several robots need different programs: `solution.<ext>` plus `solution-<name>.<ext>`.
- Python only: `challenge.py` – the file students start from.

`activity.md` starts with:

```
---
title: Secret start code
level: 3            # 1 = ★ Beginner, 2 = ★★ Intermediate, 3 = ★★★ Advanced
age: 14+
needs: Nothing else needed
robots: 2 or more   # optional
author: …
---
```

followed by the sections `## The story`, `## Your goal`, `## Step by step`, `## Hints` (numbered,
shown one at a time), `## To go further` and optionally `## For the teacher`.

The app reads these files when the library opens: an activity can be added by copying a folder.
The files in this repository are generated by `tools/make_<language>_activities.py`
(Scratch: then `tools/build_sb3.py`; Blockly: then `tools/check_blockly.py`), which also check them.
