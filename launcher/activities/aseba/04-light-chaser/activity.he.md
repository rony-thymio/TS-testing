## The story
האורות בלונה פארק רודפים זה אחרי זה במעגל. ל-Thymio יש 8 נוריות כתומות מסביב לכפתורים: בואו נגרום לאור לרוץ סביב סביב.

## Your goal
נורית אחת של המעגל דולקת בכל פעם ומתקדמת כל 150 מילישניות, בלי סוף. הכפתורים קדימה ואחורה מאיצים או מאטים אותה.

## Step by step
1. הגדירו משתנה `pos` (הנורית הדולקת, מ-0 עד 7) ומערך `circle[8]`.
2. הפעילו את טיימר 0: `timer.period[0] = 150`.
3. ב-`onevent timer0`: כבו במערך את הנורית הקודמת, קדמו את `pos` ב-1 (חוזר ל-0 אחרי 7), הדליקו את החדשה, ואז `call leds.circle(...)` עם 8 הערכים.
4. כפתור קדימה: מחזור קצר יותר (מהר יותר). כפתור אחורה: מחזור ארוך יותר (לאט יותר).

## Hints
1. הגדירו מערכים בראש התוכנית: `var circle[8] = [32, 0, 0, 0, 0, 0, 0, 0]`.
2. `pos = (pos + 1) % 8` נותן 0, 1, … 7, 0, 1…
3. `call leds.circle(circle[0], circle[1], circle[2], circle[3], circle[4], circle[5], circle[6], circle[7])`.
4. השאירו את המחזור בין 30 ל-1000 מילישניות.

## To go further
צרו „שביט”: הנורית שמאחורי הדולקת נשארת בחצי עוצמה.
