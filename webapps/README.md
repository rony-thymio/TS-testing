# Web apps

VPL3, Blockly and Scratch are static web apps released by Mobsya. Versions used by Thymio Suite 2.4.0:

| App | Release |
|---|---|
| Blockly | https://github.com/Mobsya/thymio-blockly-standalone/releases/download/v20210908.3/thymio-blockly.tar.gz |
| Scratch | https://github.com/Mobsya/scratch-gui/releases/download/v20220921.1/scratch-gui.tar.gz |
| VPL3 | https://github.com/Mobsya/vpl-web/releases/download/v20221017.1/vpl3-thymio-suite.tar.gz |

The launcher will bundle these for offline use (Stage 1).
